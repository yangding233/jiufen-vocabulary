日常流程：打开程序 → 开始新学或到期复习 → 回忆 → 按需展开巧记 → 点击忘记、模糊、认识或标记熟知。

每次操作会自动保存。底部显示“正在保存”时稍等；保存失败会恢复到操作前，处理磁盘问题后可重试。正常关闭窗口会等待保存结束。

  • 每日词量和预计完成时间：在“今日学习 → 调整计划”设置。
  • 导入自己的词：“词库与笔记 → 导入词表”，预览后保存；缺释义或音标可点“补齐释义与音标”。新词还需选择后加入计划。
  • 巧记：默认展示内置方案，可写自己的熟词线索、画面和笔记；自加词暂不自动生成巧记。
  • 备份：在“备份与设置”导出学习备份。换电脑或恢复时选择同一个 JSON 文件，先预览后恢复。
  • 内部快照：在“备份与设置 → 内部备份中心”先预览，再决定导出或恢复。

升级会沿用原来的 Windows 数据目录。旧版同步档案可读取，首次转换前完整原档案会独立保留。新版数据请使用本版恢复。
