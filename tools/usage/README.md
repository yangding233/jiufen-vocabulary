# 例句、译文、搭配与第二种助记方案

`part-01.tsv` 至 `part-04.tsv` 按原词表顺序保存 1,493 条原创学习例句。每条有一句英文、对应中文译文和 1—2 个搭配。例句使用原词表的完整词形；同一单词的所有义项不必挤进一句话中。原词条中的大小写、数字、连字符和短语写法由词表决定，编写时不借机修改词头。

`alternatives-source.tsv` 保存 120 条第二种助记方案。部分方案借另一个熟词做一次明确的删改，部分从同词族的动词、名词或形容词搭桥。人为删改不作为历史构词解释；拼音、短信缩写和字形提示不作为标准英语发音。用户是否认识提示词仍须由用户判断，不能仅凭提示词常见就认定方案适合所有人。

两类材料均为本项目逐条编写。没有批量抓取或复制词典例句。词义使用原词表给定范围，搭配与语法经过编写者及交叉阅读校对；这些检查不等于专业词典审定，也不代表每条助记已做延迟回忆效果实验。

在项目根目录运行：

```powershell
python tools/build_usage.py
python tools/build_usage.py --check
```

默认词表来自仓库内 `web/index.html` 的 `vocabulary-data`，公开源码不依赖本机 `build/` 文件。可用 `--vocabulary path/to/vocabulary.json` 指定另一份同结构词表。开发中可临时使用 `--allow-incomplete` 校验未完成的例句批次；正式编译不使用该选项。

编译器生成：

- `entries.json`：按原词表顺序排列的结构化 usage 数据，保留原 id、word。
- `usage.tsv`：带原 id 的完整可审阅清单，格式为 `id|word|sentence|translation|搭配1；搭配2`。
- `../mnemonics/alternatives.json`：120 条可供界面选择的第二种助记方案。

自动校验包括词条覆盖、id/词头匹配、重复条目、完整目标词形、中文译文、搭配数量、占位文案和助记片段精确拼接。语言自然度与借词步骤的正确性仍需人工阅读，不能仅靠拼接检查代替。
