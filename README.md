# 九分词汇 · Windows 离线背单词

九分词汇是一款以**巧记、每日计划和间隔复习**为核心的 Windows 背单词软件。内置 1,493 条常规词汇，也支持导入自己的词表、编辑资料、借助外部 AI 补全巧记，以及离线播放单词和完整例句。

**无需注册。日常学习和已经准备好的音频播放不需要网络，学习记录保存在本机。**

## 2. 第一次使用

1. 下载 Windows 程序 ZIP，解压到一个固定文件夹。
2. 保留完整解压目录，双击 `九分词汇离线学习.exe`。不要只把 EXE 单独移走，也不要直接在压缩包里运行。
3. 打开“今日学习 → 调整计划”，设置每天学多少新词、每周哪些天学新词，以及参与计划的词书。
4. 查看预计首轮完成时间，应用计划后开始新学或到期复习。
5. 下次打开程序，点击“继续上次任务”接着学。

如果从旧版升级，先看下方的[升级说明](#10-从旧版本升级)。

## 3. 每天怎样背？

日常流程是：**开始任务 → 先回忆 → 按需看释义与巧记／听读音 → 给出反馈 → 自动保存。**

| 按钮 | 什么时候用 |
| --- | --- |
| 忘记 | 想不起来，需要稍后再巩固 |
| 模糊 | 印象不清，或主要依靠提示才想起 |
| 认识 | 能够想起当前词义和拼写 |
| 标记熟知 | 已经牢固掌握，希望退出自动新学与复习 |
| 撤销 | 刚才点错了，恢复最后一次反馈前的状态 |

评分按钮可以直接使用，需要帮助时再展开释义和巧记。熟知词仍保留在词库中，可以取消熟知、恢复复习。每天新词数量和到期复习分开计数；重复出现的同一个新词不会反复消耗新词名额。

预计完成日期指的是**首轮新学完成**，之后仍需要复习。切换新词词书范围不会清空旧记录，也不会让已经加入计划的到期词停止复习；需要停止安排某个词时，请在词条中暂停。

## 4. 四个页面分别做什么？

| 页面 | 主要用途 |
| --- | --- |
| 今日学习 | 每日数量、学习日、词书范围、预计完成时间、新学、复习和继续任务 |
| 词库与笔记 | 找词、导入词表、编辑巧记与资料、AI 补全、音频生成、词书整理 |
| 学习记录 | 查看已经发生的反馈、熟知情况和复习记录 |
| 备份与设置 | 导出与恢复备份、带音频迁移、内部快照及显示设置 |

内置资料包括 1,493 条词汇、巧记和例句，5,972 个英美正常／慢速单词音频，以及 2,986 个英美整句音频。单词“播放读音”与例句右侧“听整句”分别播放相应内容。

## 5. 导入自己的单词

支持 Excel `.xlsx`、CSV、TSV、TXT 和直接粘贴。最简单的表格可以只有两列：

| 单词 | 中文释义 |
| --- | --- |
| sunflower | 向日葵 |
| raincoat | 雨衣 |

操作步骤：

1. 在“词库与笔记”点“导入词表”。
2. 选择文件或粘贴内容，核对英文、中文、例句等列的对应关系。
3. 选择新词书或已有词书，检查预览和重复词处理方式。
4. 确认导入后，选择有释义的词并点“加入计划”，或先自主回顾。

新词默认先保存到词库。只有英文也能导入，缺释义的词先作为待完善词保存；可通过离线词典、编辑或再次导入补齐。重复词优先关联或补空缺，同一个词加入多本词书时共用进度。

导入“单词＋中文”不会立即自动生成全部资料。缺音标、巧记、例句或音频时，可以用缺项筛选分别完善。详细步骤见[词表导入说明](docs/自建词书与导入.md)。

## 6. 编辑资料和巧记

打开词条，点“编辑单词资料与巧记”，可填写释义、音标、词性、英文例句、译文、搭配、来源和标签。

巧记可以写成简单的“熟悉线索＋联想画面”，也能添加实际片段和拼写说明，例如：

> sun（太阳）＋ flower（花）→ sunflower（向日葵）

多条方案按序号集中展示。程序会检查片段能否按顺序还原目标拼写，包括大小写、空格与连接符；借词的增删换步骤需要写清楚。资料修改保留原词条和学习记录，这个入口不把已学习的英文词条直接改成另一个词。

“补齐释义与音标”会查本机参考词典并给出候选，默认保护已有内容。它补的是文字资料，补音标不等于已经生成声音。参考词典有收录和质量限制，音标未区分英美时不会伪造两种口音。[查看补全说明](docs/离线资料补全.md)。

## 7. 怎样交给 AI 补全？

软件提供任务与结果入口，**不自动登录或调用 AI，也不要求填写 API 密钥**。

1. 筛选词书或勾选需要完善的词，点“交给 AI 补全”。
2. 选择需要补的字段和每批词数，点“生成待补任务”。
3. 核对任务内容，复制完整提示词发给你使用的外部 AI；也可导出任务 JSON 保存。
4. 将 AI 返回的 JSON 粘贴或载入文件，点“检查结果并预览”。以前的任务可先载入原任务文件。
5. 检查已有值、候选值和来源，勾选需要的字段，再点“采用选中的资料”。

任务默认不包含学习反馈、私人笔记和简单个人联想。编号错误、拆分无法还原或资料已经过期时，会拒绝或提示重新核对。已有非空内容默认保留，替换需要明确选择；部分采用后可以继续处理剩余字段。

**结构正确不代表内容准确或一定好记。**请检查 AI 的词义、音标、来源和联想是否适合自己。面向 AI 的返回格式与示例见[AI 补全指南](AI补全指南.md)，使用步骤见[资料编辑与 AI 补全](docs/资料编辑与AI补全.md)。

## 8. 为自加词或例句生成声音

内置单词和内置例句已经有声音，日常播放不需要生成组件。只有新增、修改的文字缺声音时才需要以下步骤：

1. 下载并完整解压“可选离线语音组件”，可以放在主程序目录外。
2. 在“词库与笔记”展开“离线音频：为自加词和例句生成读音”。
3. 点“选择语音组件”，选择含 `runtime`、`models` 和 `ffmpeg.exe` 的那一层文件夹。
4. 选择已勾选词条或当前筛选范围，再选择单词、英文例句或两者，以及英式／美式。
5. 点“生成缺失音频”，查看进度；完成后试听。可以取消，失败项目可稍后重试。

组件自带运行环境，用户无需手动安装 Python。准备好后可离线生成；软件不会自动下载模型。音色沿用英式 Emma、美式 Heart。已存在的相同内容会复用；修改例句正文后，不会继续把旧声音当作新句子播放。组件移动位置后重新选择即可。

## 9. 备份、分享和换电脑怎么选？

| 文件／功能 | 包含什么 | 适合什么用途 |
| --- | --- | --- |
| 学习备份 JSON | 词条资料、词书、个人笔记、进度和历史；不带音频文件 | 日常另存和恢复进度 |
| 完整迁移 ZIP | 学习档案、自加音频及相关内容包 | 换电脑时同时带走自己的进度和声音 |
| 词书资料包 JSON | 词汇、章节、巧记、例句等文字资料；不带学习历史、私人笔记或音频文件 | 分享或导入一份词书资料 |
| 内部快照 | 软件保留的本机档案副本 | 预览并恢复误操作前的记录 |

日常请在“备份与设置”另存学习备份到程序目录外。换电脑且需要自加声音时，使用“完整迁移包（包含自加音频）”。恢复会切换到所选备份状态，先核对预览并保存当前档案，不合并两份独立的学习历史。完整迁移包包含个人记录，不要当作普通词书包分享。

程序每次操作自动保存；“正在保存”表示尚未完成，“已保存”才表示写入成功。失败时会提示并回退本次操作。正常关闭和刷新会等待保存；内部快照仍在同一电脑上，不能代替外部备份。

词书归档、恢复、章节顺序、移出词条、资料包和批次撤销都在“词库与笔记 → 词书整理、资料包与撤销”。撤销只处理仍可安全还原的资料；后续改过的字段会跳过，不撤销后来产生的学习反馈。[查看详细说明](docs/词书整理与资料包.md)。

## 10. 从旧版本升级

1. 在旧版中导出完整备份并确认保存，然后退出旧程序。
2. 将 2.1.0 解压到新文件夹，打开新版 EXE。不要同时用新旧程序学习。
3. 核对已学词、熟知、笔记和任务断点，再继续学习。

同一 Windows 用户会沿用数据目录：`%APPDATA%\九分词汇离线学习\offline-v1`。旧同步格式首次转换前会保存完整原档；已有 Windows 本地档案继续读取。需要退回旧程序时使用升级前的备份，新资料请使用新版读取。

项目自 2.0 起仅维护 Windows，已移除 iPhone、USB 同步与签名续签流程。

## 11. 常见问题

**导入了单词，为什么今天没有自动出现？** 新词先保存在词库，已有释义后需要选择并加入计划，还会受每日新词数量和词书范围限制。

**只有单词和中文，其他内容怎么办？** 可以手动编辑，先查离线词典补音标，再通过 AI 任务补巧记、例句和搭配；需要声音时另行生成。

**“听整句”提示没有声音？** 先确认有英文例句。新增或修改后的句子需要生成对应音频，旧缓存不会套用到新正文。

**没有装语音组件还能用吗？** 可以。背词、资料编辑、导入、备份和已准备音频的播放都可使用。

**换了程序文件夹会丢进度吗？** 同一 Windows 用户的进度保存在上述数据目录。换电脑需要导出备份，声音也要迁移时使用完整迁移包。

## 12. 开发者说明

从源码运行需要 Windows、Node.js 24 和 Python 3。普通用户下载程序包即可。

```powershell
npm ci
npm --prefix apps/windows ci
npm run prepare:web
npm run desktop
```

主要检查与打包命令：

```powershell
npm test
npm --prefix apps/windows test
npm run test:audio
npm run verify:resources
npm run test:ui
npm run test:desktop
npm run desktop:package
```

界面测试使用 Microsoft Edge。真实桌面测试使用隔离的 `JIUFEN_DATA_DIR`，不能操作日常学习数据库。可选生成组件测试需要先准备组件，另运行 `npm run test:audio:components`。

| 目录 | 职责 |
| --- | --- |
| `web/` | 学习界面和随包离线资源 |
| `shared/` | 词书、资料、AI 任务、复习及音频规则 |
| `apps/windows/` | Electron、SQLite、本机音频服务和打包 |
| `tools/` | 资源维护、可选组件构建和发行检查 |
| `tests/` | 数据、迁移、界面及真实桌面回归 |

本地验证包含 101 项数据、存储及音频检查，9 组界面回归和 6 组真实打包版检查。容量样本覆盖 10,000 词、20,000 条历史和 1,000 套巧记；这些结果不表示所有电脑都有相同速度。[查看验证边界](docs/2.1开发验收.md)。
