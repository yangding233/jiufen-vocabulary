# 九分词汇

一款以**巧记和每日复习**为核心的 Windows 离线背单词软件。内置 1,493 个常规词汇，也可以导入自己的词表。无需注册，学习记录保存在本机。

**[下载 Windows 2.0.0](https://github.com/yangding233/jiufen-vocabulary/releases/download/v2.0.0/JiufenVocabulary-Windows-2.0.0.zip)** · [查看发行版](https://github.com/yangding233/jiufen-vocabulary/releases) · [详细使用说明](docs/简单使用说明.md)

## 快速开始

1. 下载并解压 Windows 压缩包，保留整个文件夹，双击 `九分词汇离线学习.exe`。
2. 打开“今日学习 → 调整计划”，设置每天学多少新词和每周学习日，查看预计完成时间。
3. 开始新学或到期复习，先回忆，需要时查看释义和巧记，再选择“忘记／模糊／认识”。下次打开可继续上次任务。

“标记熟知”适合已经牢固掌握的词，标记后不再自动安排复习；误点可以撤销，也可以在词库恢复。

## 主要功能

| 入口 | 可以做什么 |
| --- | --- |
| 今日学习 | 每日计划、预计完成时间、熟词搭桥与巧记、间隔复习、离线英美读音 |
| 词库与笔记 | 搜索单词、个人联想与笔记、自建词书、导入词表、补齐释义与音标 |
| 学习记录 | 查看学习反馈、历史和复习安排 |
| 备份与设置 | 导出和恢复学习备份、预览内部快照、调整文字大小等偏好 |

导入支持 Excel `.xlsx`、CSV、TSV、TXT 和粘贴。先核对列与重复项，再确认保存；新词需要自行加入学习计划。只有单词和中文也能导入，缺少的释义或音标可以查本机参考词典。**新导入的词暂不自动生成巧记或音频，例句整句朗读仍在后续计划中。**

## 保存、备份与升级

- 每次操作自动保存；看到“已保存”后即可放心退出。保存失败时会提示并回退本次操作。
- 定期在“备份与设置”导出完整学习备份 JSON，保存到程序目录外。恢复前先预览，再按提示另存当前记录并确认恢复。
- 从旧版升级：**先导出备份并退出旧程序，再打开新版。**新版沿用原数据目录，并在转换旧档案前保留完整副本。
- 数据目录：`%APPDATA%\九分词汇离线学习\offline-v1`。新版数据请用新版读取，需要退回旧版时使用升级前的备份。

2.0.0 已收敛为 Windows 单机版，移除了 iPhone 和 USB 同步。日常学习直接保存当前状态，减少按钮等待；旧版备份仍可读取。

## 从源码运行

需要 Windows、Node.js 24 和 Python 3。

```powershell
npm ci
npm --prefix apps/windows ci
npm run prepare:web
npm run desktop
```

基础检查：`npm test`、`npm --prefix apps/windows test`、`npm run verify:resources`。打包：`npm run desktop:package`。界面直接维护在 `web/`，共享数据逻辑位于 `shared/`。
