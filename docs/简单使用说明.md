# 九分词汇 1.2.0 · 简单使用说明

电脑和 iPhone 都可以断网背单词。平时各自在本机保存；想把两边的学习记录合到一起时，再用数据线同步。

第一次用，可以先完成三件事：打开程序 → 点“调整计划”设好每天的新词数 → 点“开始新学”。已经有未完成任务时，点“继续上次任务”。

## 1. 打开和安排每天词量

- **电脑**：解压 Windows 压缩包，保留整个文件夹，打开“九分词汇离线学习.exe”。不要只把 EXE 单独移走。
- **手机**：打开已经签名安装好的“九分词汇”。日常学习不需要网络。
- 在“今日学习 → 我的学习计划”点 **“调整计划”**，填写每天想学多少个新词，并选择一周中的学习日，最后点 **“应用计划”**。
- 想在某天完成首轮，可以展开 **“有目标日期？帮我倒推每天词量”**，选择日期，点 **“按日期计算每日词量”**，看过预览后再应用。

“预计首轮完成”只估算把计划内的新词学过一遍的时间，之后仍要复习。当天没学完的词会保留，第二天按每日额度重新安排，不会把两天的新词量直接叠起来。

新词和旧词复习分开计算。未来 7 天的学习负担和分钟数是粗估，可以分几次完成；感觉太多时，自己调低新词量即可。

## 2. 开始背：四个按钮怎么选

点 **“开始新学”** 学新词；有旧词到期时，点 **“开始到期复习”**；之前中途退出了，就点 **“继续上次任务”**。按钮后可能显示本组词数。

看到词后，先在心里想意思，需要帮助时再点“想不起来？看熟词线索”或“查看释义与拆分巧记”。**不用先展开答案，也能直接点下面的四个按钮。**

| 按钮 | 什么时候用 |
| --- | --- |
| 忘记 | 这次想不起来，稍后再练 |
| 模糊 | 有印象，但不确定，或依靠提示才想起 |
| 认识 | 这次能够想起，继续下一个词 |
| 标记熟知 | 早已牢固掌握，不需要再自动安排这个词 |

点错后，用 **“撤销上次反馈”**。已经标记熟知的词也能在“词库与笔记”筛选“熟知词”，点开后选择 **“取消熟知，恢复复习”**。

想暂时停下，点 **“暂停并收起”**，下次继续。**“自主回顾”** 适合额外练习，会保留反馈，但不改变长期复习日期。

## 3. 听读音、慢速和听音回忆

- 在词卡点 **“▶ 播放读音”**，口音可以选 **“英式”** 或 **“美式”**，速度可以选 **“正常”** 或 **“慢速”**。
- 在“回忆方式”选 **“听音，回忆意思”**，点播放先听，再按需要查看答案、选择反馈。
- 软件自带 **Kokoro 神经合成参考音**，英式和美式各有正常、慢速音频。它们已提前生成，断网即可播放，手机不需要下载语音模型。慢速文件保持音调，不必另外设置。
- 少数词有不同词性或意思对应的读法，播放提示会注明顺序；听到两种读法时，请结合词义核对。中文谐音、拼音和字母编码只用来助记，不是英语发音。

如果想练拼写，已有 **“看中文，回忆拼写”** 模式。愿意时输入答案，再核对；平时不需要强制输入，也没有“移开视线再拼写”的必做步骤。

## 4. 巧记不顺手，就换自己的线索

展开巧记后，依次看“字母怎样搭起来 → 故事怎样连到意思 → 怎样还原拼写”。熟词变形会先给基础词，再写出变形步骤。

有多个内置巧记的词，会在同一处按 **“① 巧记 1”“② 巧记 2”** 连续显示完整线索、画面和拼写步骤，不用切换下拉框。只有一条时直接显示，不加多余选项。

点 **“写自己的巧记”**，或到“词库与笔记”点开单词，在“我的拆分／熟词线索”“我的联想画面”里填写，再点 **“保存我的联想与笔记”**。你的个人联想优先显示，更新内置内容也会保留。清空个人内容并保存后，重新使用内置线索。

觉得某条内置线索不适合，也可以点 **“这条线索不适合我”**，以后需要时再恢复。

## 5. 例句、搭配和学习记录

展开答案后可以看 **“常用例句与搭配”**：先读英文短句，再看中文，顺便记住一两个常用搭配。也可以切换 **“短句遮词回忆”**，把词放回句子中练习。

直接使用四个反馈按钮，无需另外选择“本次回忆方式”。软件按是否打开提示、展开答案自动记录：未用提示且未看答案就点认识，记作独立回忆；用过提示，记作提示后反馈；看过答案再反馈，记作未细分。旧版已经保存的回忆标记保留。

到 **“学习记录”** 查看：

- 独立回忆、使用提示等已记录情况；看过答案后的未细分反馈不会自动当作独立想起。
- **“最近的拼写错题”**：练过拼写并提交反馈后，可以回看拼错的位置，点词再练。
- **“需要换巧记的词”**：回看之前标记线索问题的词，查看其他编号巧记或写自己的线索。

## 6. 手机和电脑用数据线同步：先手机，后电脑

**先把两端都更新到 1.1.0 或更新版本。** 连接可传数据的 USB-C 数据线，手机解锁，按手机提示信任电脑，并让“九分词汇”留在前台。

1. **手机**：先展开顶部 **“数据线同步”**，点 **“准备与电脑同步”**。
2. **电脑**：展开顶部 **“数据线同步”**，点 **“数据线同步”**。没有识别到手机时，可以先点 **“检查手机连接”**。

等手机显示已保存并发送确认，电脑显示 **“双向同步完成”**，再在手机点 **“退出同步准备”**，拔线继续学习。同步等待时先不要继续背词。

第一次配对前，先分别导出备份并核对：**有进度的一端可以初始化尚未学习的一端**，电脑再勾选“首次配对：允许用已有进度初始化尚未学习的一端”。日常同步通常不用再勾。

如果两边原本就有各自独立的学习记录，软件会拒绝直接覆盖。先保留两份完整备份、核对要继续使用哪份，不要靠反复勾选首次配对来覆盖另一端。

## 7. 内容更新和进度备份：是两种不同文件

| 文件 | 用来做什么 | 在哪里操作 |
| --- | --- | --- |
| 内容包 | 更新内置巧记、替代方案、例句与搭配；不包含你的学习进度 | “备份与设置 → 离线内容更新” |
| 完整同步档案 | 保存你的学习记录、个人联想、笔记及同步所需信息 | 顶部“数据线同步 → 同步档案备份与恢复” |

**更新内容**：在“离线内容更新”点 **“导出当前内容包”**，或通过 **“导入新版内容包”** 选择完整词库内容文件。导入后个人联想和进度会保留；正常 USB 同步也会把较新的内容带到另一端。两边都先升级到 1.1.0，再交换内容。

**备份进度**：展开“同步档案备份与恢复”，点 **“导出完整同步档案”**。

- 电脑：选一个程序文件夹以外、容易找到的位置，完成保存。
- 手机：分享面板中选 **“存储到文件”**，选好位置并完成保存，再到“文件”里确认能找到它。

建议定期保存，升级、续签和恢复前再留一份。内容包不能替代学习档案备份；只打开分享面板或取消保存，也不等于已经备份。

## 8. 找回内部快照：先预览，再决定

在 **“备份与设置 → 内部备份中心”** 点 **“查看内部快照”**，再点某个时间，核对词数、已接触词数和反馈数量。**预览不会改变当前学习档案。**

- **只想留底**：点 **“导出这份恢复副本”**，另存到电脑目录或手机“文件”。
- **确实要从这一份继续学**：先导出当前完整同步档案，再点 **“建立独立恢复档案”**，读完提示并确认。当前使用的进度会切换到选中的快照；原来的档案也会另外保留快照。

独立恢复后，在这一端导出完整同步档案。另一端先备份当前记录，再在顶部“恢复／合并同步档案”选择同一份恢复档案，读完提示并确认切换。两端使用同一档案后再数据线同步。正常 USB 同步不会直接覆盖另一个独立档案，无需删除 App 来清空记录。

内部快照只保留有限份数，并且仍在本机。手机丢失、卸载 App 或电脑文件损坏时，它可能一起丢失，因此还要保留一份外部完整同步档案。

## 9. 升级和续签时怎么保留记录

1. 先导出完整同步档案，并尽量完成一次双向同步。
2. 电脑升级时保留旧程序文件夹和备份；新程序也要保留整个目录。
3. 手机继续使用原来的签名身份与安装设置，覆盖更新或续签。**不要先卸载旧 App。**
4. 新版本打开后，核对进度、笔记和熟知标记，再继续同步。

本轮的新音色与界面需要在电脑和手机分别安装 1.2.0；只同步进度或导入内容包不会替换音频。安装包用于安装软件，完整同步档案用于保存你的进度。续签需要用到安装工具；平时的离线学习和数据线同步不需要网络。

## 常见问题

**两端巧记内容不同怎么办？** 先核对“备份与设置 → 离线内容更新”里的内容版本，再正常同步，较新内容会带到另一端。如果提示相同版本的内容不一致，保留两边的内容包和学习档案，换用同一份完整内容包，不要手动改文件里的版本号。

**提示旧版本被拒绝？** 先把手机和电脑都升级到 1.1.0 或更新版本，再重新“准备与电脑同步”。不要只更新一端。

**电脑显示手机尚未确认，是完成了吗？** 还没有。保留两端程序和记录，手机保持解锁、App 在前台，重新连接后再试。只有电脑显示“双向同步完成”才算这一轮完成。

**点了导出但又取消，算备份了吗？** 不算。电脑需完成保存；手机需完成“存储到文件”并确认文件确实存在。取消保存或分享不会记为已保存的外部备份。

**我只想直接背，不想额外选一堆标记。** 可以。已去掉额外的回忆标记选项，拼写练习仍为可选模式；按自己的习惯使用忘记、模糊、认识、标记熟知即可。

## 自建词书与导入

打开“词库与笔记 → 导入词表”，选择本地 Excel／CSV／TSV／TXT 或粘贴词表，选择工作表和列，预览重复项后确认。导入后新词默认不进计划；选中已有释义的词再加入计划。完整步骤见 [自建词书与导入](自建词书与导入.md)。电脑、手机需要同时升级到 1.2.0 才能同步新词书。
