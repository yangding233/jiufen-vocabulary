# 简单使用说明 · Windows 2.1

## 每天怎样学

1. 打开“今日学习 → 调整计划”，设置每日新词数量和学习日，查看预计首轮完成时间。展开“每日新词来自哪些词书”，可选择学习范围，再随每日词量一起应用计划；也可单独点“应用词书范围”。
2. 有旧词到期时先复习；有断点时点“继续上次任务”。先回忆，需要时再展开巧记和释义。
3. 按实际情况选择“忘记／模糊／认识”。已牢固掌握的词可“标记熟知”，误点可撤销。
4. 反馈自动保存。显示“正在保存”时稍等；正常关闭和刷新会等待保存完成。保存失败时本次操作会回退，请处理磁盘问题后重试。

每日新词共用一份总量，同一个词出现在多本词书中只计一次。切换学习范围不停止旧词到期复习；需要停止安排时单独暂停。预计完成时间表示首轮新学完成，不表示以后不再复习。

## 导入自己的单词

在“词库与笔记”点“导入词表”，选择 Excel .xlsx、CSV、TSV、TXT，或直接粘贴。指定列、词书、重复项处理方式，核对预览后确认。只有单词和中文也能导入；新词先保存在词库，选择后使用“加入计划”安排学习。

缺释义或音标时，点“补齐释义与音标”查本机参考词典。已有内容默认保护，候选须结合词义核对；补文字资料不会自动生成音频。

## 直接修改资料和巧记

打开词条，点“编辑单词资料与巧记”，可修改释义、音标、词性、例句、译文、搭配、来源和标签。英文拼写与历史反馈保持原记录。

“添加一条巧记”可填写熟悉线索、联系词义的画面和拼写说明；需要拆分时增加实际片段及提示。片段必须按顺序还原原词的大小写、空格和连接符。也可不拆分，直接写清楚熟词线索和画面。多条巧记按序号一起展示。

词库可筛选缺释义、缺音标、缺巧记、缺例句和缺音频。已有个人线索与笔记仍可继续使用；巧记属于助记，不作为真实词源或英语发音规则。

## 交给 AI 补资料

1. 先筛选词书或勾选词条，点“交给 AI 补全”，选择字段和每批词数，再点“生成待补任务”。
2. 核对任务内容，复制完整提示词发给你选用的外部 AI；也可导出任务 JSON，保留供以后导回。
3. 将 AI 返回的 JSON 粘贴或载入结果文件，点“检查结果并预览”。
4. 检查每个词、候选资料和来源，勾选需要采用的字段，再点“采用选中的资料”。没有把握的内容可以不采用。

软件不自动登录或调用 AI。任务默认只带词汇资料，不带学习历史、私人笔记或简单个人联想；生成期间又修改过的资料会提示重新核对。程序能检查格式和字母还原，不能代替对词义、读音和联想效果的判断。

## 听单词、听整句与生成读音

单词“播放读音”播放当前词；例句右侧“听整句”朗读完整英文句子。英式 Emma、美式 Heart 以及速度可选择。已准备的声音可以断网播放；缺少句子或对应音频时按提示准备。

在“词库与笔记”展开“离线音频：为自加词和例句生成读音”。选择已勾选词或当前筛选范围，再选择单词／英文例句／两者和口音，点“生成缺失音频”。可以查看进度、取消，失败项目稍后重试；相同内容的已生成声音会复用。

生成需要可选的本地语音组件及模型。先准备组件文件夹，再点“选择语音组件”；主程序不自动下载，也不要求播放时运行模型。准备好后可本机离线生成。修改英文正文后旧音频不会当作新正文继续使用。

## 整理词书、分享资料和撤销批次

在“词库与笔记”选一本词书，展开“词书整理、资料包与撤销”，可归档、恢复、调整章节顺序或将已选词移出当前词书。移出保留单词、历史、笔记及其他词书关联；没有所属词书的词可通过“查看未分组词”找到。

“导出当前词书资料包”只导出词汇、巧记、例句等资料，不带学习历史和私人笔记。导入资料包时先核对关联词和差异，默认只补空缺；明确需要时才替换已有资料。资料包用于分享资料，完整备份用于迁移自己的进度。

展开“撤销最近的资料批次”，先预览再撤销可安全还原的资料。后来已经改过的字段会跳过；不会撤销之后新增的学习反馈，也不会删除已经学习的新词。

## 备份、换电脑与旧版升级

定期在“备份与设置”导出完整学习备份 JSON，放到程序目录外。JSON 保存文字资料、词书、笔记和进度，不能单独带走音频文件。

需要带走自加音频时，使用“完整迁移包（包含自加音频）→ 导出完整迁移包”。恢复时先“预览迁移包”，核对词数、历史和音频数量，再确认恢复；当前档案会先保留独立副本。

普通 JSON 与内部快照也可预览和恢复。恢复会切换为备份状态，不合并两份独立历史。升级前先导出完整备份并退出旧程序，再打开新版。

用户数据继续保存在 %APPDATA%\九分词汇离线学习\offline-v1。旧格式转换前会保留完整副本；新版添加的资料请用新版读取。需要退回旧程序时使用升级前备份。
