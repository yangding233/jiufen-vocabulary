# 巧记内容与维护

## 本轮完善（2026-11-03）

原词库有 428 条“待补巧记”和 109 条“形近对照候选”。本轮逐词补上拼写提示和目标词义场景，并重写 156 条短语的组成词提示。另对较弱的派生词、相互反推的基础词补独立方案。

当前数量以 `tools/mnemonics/coverage-report.json` 为准。所有 1,493 条均有内置线索，保留原表词形、顺序、大小写、词义和音标。这里的“有线索”包括熟词增删替换、拆分、完整短语和基础词变形，不表示每条都是词根分析，也不表示已经验证个人记忆效果。

例如：

- `age` 借 `cage`（笼子）去开头 `c`，把笼子旁的年龄牌作为语义线索。
- `Africa` 用 `A` 形金字塔、`Friday` 前三字母 `fri`、`car` 去 `r` 的 `ca`，连接一张非洲旅行照片。
- `skin` 用 `ski`（滑雪）去 `i` 得 `sk`，再接 `in`（里面），联系滑雪服里面的皮肤。
- `a radio program` 按原短语保留空格，补上 `program` 的节目义；显示组成词，不给空格单开提示卡。

## 编辑与编译

- `tools/mnemonics/batch-*.json`：原缺口的逐词方案。
- `tools/mnemonics/extra-*.json`、`refinements.tsv`：其他独立重写方案。
- `phrases.tsv`：完整短语的组成词提示和场景。
- `base-glosses.tsv`：未加入学习词表的基础提示词释义。

JSON 方案需要 `word`、`parts: [{text, cue}]`、`scene`。`text` 必须是目标单词的真实字母片段，按顺序拼接后等于原词。借词变换要在 `cue` 中写清楚删、加、换哪些字母。整个熟词增删换字，也可作为一个完整 `text` 片段。

```powershell
python tools/update_mnemonics.py
python tools/update_mnemonics.py --check
node --test tests/mnemonics.test.cjs
node tests/mnemonic-ui.test.cjs
```

编译器只更新 `web/index.html` 的内置 `memory` 字段和方法筛选项，不打开学习数据库。派生词卡分别显示基础词提示、基础词联想和到本词的变形步骤；基础词链有循环时拒绝编译。

两端启动时从随安装包提供的词库读取内置巧记。个人 `memoryAnchor`、`memoryScene` 和停用选择仍来自本机学习卡，优先展示。内容版本不参与 USB 档案身份和操作合并，不需要重建学习档案。

## 审阅边界

本轮对新方案做了逐词编写与交叉文字审查，并校验词头覆盖、片段拼接、变形操作、基础词链和空提示。交叉审阅修正过 `certificate`、`course`、`cookery` 等“片段写对但借词操作说明写错”的问题。字母拼接校验本身查不出所有语言或故事问题，后续发现不顺手的提示仍应改写。

拼音、首字母、图形与中文近音只作为人为编码；英语读音仍看音标。任意拆分和故事不作为历史词源。使用者不认识提示词时，可以停用内置方案或写自己的熟词与画面。

词义不确定的条目查阅过 Cambridge 的 [compulsory](https://dictionary.cambridge.org/dictionary/english/compulsory)、[instinctive](https://dictionary.cambridge.org/us/dictionary/english/instinctive)、[insulation](https://dictionary.cambridge.org/us/dictionary/english/insulation)、[nitrogen](https://dictionary.cambridge.org/us/dictionary/english/nitrogen)、[species](https://dictionary.cambridge.org/dictionary/english/species)、[terminal](https://dictionary.cambridge.org/dictionary/english/terminal)、[textile](https://dictionary.cambridge.org/us/dictionary/english/textile)，以及 Oxford 的 [philosopher](https://www.oxfordlearnersdictionaries.com/definition/english/philosopher)。词典用于核查词义，具体故事均为本轮原创，没有复制第三方助记全文。

方法参考仍为开发时的三套课程总结和两份 PDF。熟悉线索与目标意思之间需要有可理解的联系，可另见 [APA 对 mnemonic 的定义](https://dictionary.apa.org/mnemonic)和 [Vanderbilt IRIS 的教学介绍](https://iris.peabody.vanderbilt.edu/module/ef2/cresource/q1/p04/)；这些资料不构成本词库记忆效果已经验证的证据。

## 使用新版

Windows 打开新版目录中的程序，会继续使用相同位置的本机学习档案。iPhone 使用同一个 Apple 账号和原有 App 标识签名覆盖安装新版 IPA；先在两端各导出完整同步档案备份。保留旧 App 后覆盖安装，避免先卸载导致应用数据被系统删除。

USB 同步交换学习进度和个人联想。内置巧记随安装包更新，因此电脑和手机都需要换到包含本轮内容的版本。
