# 补齐释义与音标

导入的词表只有英文，或只有“英文＋中文意思”时，可以使用词库里的 **“补齐释义与音标”**。软件从随安装包提供的离线词典和已有词库查找资料，先给出预览，采用后保存到本机学习档案。查询与采用过程不需要联网。

## 1. 选择要检查的词

打开 **“词库与笔记”**，选择词书，或先勾选部分词，点击 **“补齐释义与音标”**。按需要选择 **“当前词库筛选范围”**、**“已选词条”** 或 **“全部词条”**，再点 **“查找可补资料”**。当前筛选范围同时遵守所选词书、章节和搜索条件。

资料缺失的词会显示可补字段、候选值和资料来源。已有内容默认保留；你的中文意思、自己修改的音标和个人笔记不会因查到词典内容就自动被替换。

## 2. 检查候选资料

优先核对英文拼写、中文意思和读音是否适合你正在学习的词义。需要的字段可以采用，不需要的字段可以取消。

- **精确匹配**：候选拼写与词条一致，可以补缺失资料。
- **大小写不同或存在多个候选**：先明确选择词条，再检查内容；专名与普通词可能含义不同。
- **词形变化或原形建议**：建议只帮助找到相关词，不会直接把原形音标写到过去式、复数或其他变化形式上。
- **没有查到**：保留原词条，留待手动填写或后续通过 AI 补全任务处理。

词典可能收录多个词义。你已经填写的中文意思会继续保留，查到其他词义不代表需要替换它。若确实要替换非空资料，需在预览中明确选择并检查差异。

对于已知会随词性或含义改变读音的同形词，音标不会默认勾选。先核对你要记的词义和词性，再决定是否采用该候选读音；保存释义不要求同时采用音标。

## 3. 音标和来源怎样看

补全结果会保留词典名称、版本及匹配信息，便于以后核对来源。离线词典音标未明确区分英式和美式时，按普通词典音标展示；软件不会把同一份音标复制成两种口音。

音标是文字资料，读音音频是另一类资源。补齐音标后，不会自动出现新词的离线声音。

## 4. 采用并继续学习

核对预览后，点击 **“保存选中的补全资料”**。保存成功后，窗口会继续显示尚未补齐的资料；没有剩余需要保存的内容时，保存按钮会禁用。预览和关闭不会改动词库。保存失败时，原记录保留，可以查看提示后重试。

补齐释义后，原先的“待完善释义”词可以选中加入学习计划。补全本身不改变每日新词额度，也不把所有补齐的词自动加入当天任务。

已有词的编号、反馈历史、熟知状态、个人笔记及复习日期保留。补全后的资料随 Windows 本机学习档案保存，并包含在完整学习记录备份中。2.0.0 起不再提供手机功能或数据线同步。

## 5. 这一轮功能范围

本功能用于从已有资料中补释义、音标和可用的词性信息。当前开发版另有“交给 AI 补全”任务导出／结果导回、手动巧记编辑和可选本地音频生成；它们与词典查询独立，需要配套新版程序。离线词典没有收录或无法明确匹配的内容，会保留为待确认，不编造结果。

词典具体版本、来源和许可见随软件附带的《离线词典来源》。词典有收录范围和数据质量限制；遇到专业词、专名、多音词或你发现的不合适资料，可以保留自己的内容，另行核对。
