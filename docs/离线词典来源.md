# 离线词典资料来源与维护

本项目的“释义与音标补全”使用随程序提供的 ECDICT 常用词子集。Windows 程序读取本机资料，查询时不访问网站、不上传单词或学习记录。补全结果作为待采用的词典参考资料；用户导入或手动编写的资料优先保留。

## 子集选择

程序包含 50,000 条资料：先选择带考试标签、Oxford 标记、Collins 标记或 BNC／当代词频位于前 30,000 的合格词条；再按基础词优先级补入原始数据确实收录的相关词形。此范围覆盖常见学习场景，专业词、生僻词和短语可能查不到。

选择过程保持原始拼写与大小写，不把同名专名、大小写词、单复数或其他词形合并。过长、含可执行标记／控制字符、无中文释义等不适合直接显示的记录被排除。最终数量与文件校验值见 `web/dictionary-manifest.json`。

- `meaning` 来自原库的 `translation`，保留其释义与明确标注的词性。
- `phonetic` 保留原库转写，不复制成英式／美式两份。
- `partOfSpeech` 仅提取中文释义行中明确的 `n.`、`vt.` 等标签；原库 `pos` 中的语料百分比不当作词典词性释义使用。
- `exchange` 保留原库词形关系，用于显示原形／变化形式建议；不会把原形的音标直接用到另一个词形。

## 音标范围

界面标示为“词典音标（保留原库标记，未分英美）”。原库含有旧式或混合转写，例如撇号重音、`ә` 和冒号等；本项目保留原文，不通过简单替换宣称已变成现代标准 IPA。读音会随词性或语境变化的词，应核对对应释义。空音标保持为空，不编造、也不从原形借用。

本数据不提供新词声音、例句音频或巧记。它也不为未收录词即时生成释义；这些内容属于后续功能。

## 开发维护

日常源码构建直接使用已提交的 `web/dictionary-data.js` 和清单。数据脚本按需加载，只有开启补全时才创建词典索引。

维护者首次准备数据可运行 `python tools/build_dictionary.py --download`。该显式选项只从上游固定提交下载 CSV、README 和 LICENSE，并核对固定 SHA256。原文件位于忽略目录 `build/vendor/ecdict/<commit>`，不会作为开发原件再次装入程序。

已准备源文件后，运行 `python tools/build_dictionary.py` 可离线重建；`python tools/build_dictionary.py --check` 离线比对生成结果，不联网。清单记录子集数量、来源提交、源文件和生成资源的摘要。更换上游版本或选择规则时，应同步更新固定校验值、数据版本、本文与测试，再进行词义／音标抽查。
