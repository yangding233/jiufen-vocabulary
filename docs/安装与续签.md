## 2. 用 Windows 给 iPhone 安装 App

安装、签名和续签需要电脑能够联网；安装完成后的日常学习和本项目的数据线同步可以离线进行。

1. 安装并打开 Sideloadly。
2. 用可以传输数据的数据线连接 iPhone，解锁手机。如果手机询问“要信任此电脑吗”，在手机确认，并由你自己输入锁屏密码。
3. 确认 Sideloadly 的设备栏出现这台 iPhone，再把 `JiufenVocabulary-unsigned.ipa` 拖入窗口。
4. 在 Sideloadly 中填写你的 Apple 账号，开始签名安装。**账号密码、双重验证码均由你自己在工具或 Apple 的验证流程中输入，不发到聊天里。**
5. 安装结束后，在手机主屏幕找到“九分词汇”。
6. 如果手机提示开发者尚未信任，到“设置 → 通用 → VPN 与设备管理”，按系统提示信任本次签名所用的开发者身份。菜单仅在存在相应描述文件时出现。
7. 如果手机提示需要开发者模式，到“设置 → 隐私与安全性 → 开发者模式”，按系统提示开启、重启并再次确认，然后重新打开 App。以手机实际提示为准，见 [Apple 开发者模式说明](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)。

Sideloadly 官网列出了 Windows 所需的 iTunes、iCloud 桌面组件。**这台电脑已经具备 Apple 设备连接组件，先让 Sideloadly 检测，按它指出的具体缺项处理。**不要为了开始安装就先卸载已有的 Apple 设备软件；如果检测失败，应先核对具体错误和官网兼容要求。[Sideloadly 官方下载与 FAQ](https://sideloadly.io/)

本项目默认 App 标识为 `com.jiufen.vocabulary`。签名工具可能更改最终标识；请保留安装设置，并从签名工具的安装日志或应用信息核对实际 Bundle ID。若实际值不同，之后在 **Windows 学习程序顶部的“手机 App 标识”**填入实际值，否则电脑可能找到手机却找不到本 App。

## 3. 先把原网页进度迁入 Windows

首次配对采用“电脑保留已有进度，手机作为空白设备接收”的顺序。

1. 在原来的 `C:\Users\23353\Desktop\软件\雅思词汇学习.html` 中打开“备份与设置”，导出完整 JSON，另存一份留底。
2. 打开新的 Windows 学习程序，**尚未在新程序学习时**，到“备份与设置”导入这份 JSON。
3. 核对已学单词、熟知标记、个人笔记、每日计划和任务断点。
4. 在顶部展开“同步档案备份与恢复”，导出“完整同步档案”，保存到 App 目录以外的普通文件夹。
5. 手机首次打开后，先保持空白，不要另起一份学习进度，直接准备接收电脑档案。

如果新的 Windows 程序已经有学习记录，先导出完整同步档案，再核对如何迁移，不要反复用旧 JSON 覆盖。两端都已有不同来源的独立进度时，程序会拒绝直接初始化，需先分别备份并处理档案来源。

## 4. 完成第一次数据线同步

1. 数据线连接手机和电脑，手机保持解锁、“九分词汇”在前台。
2. 手机点击 **“准备与电脑同步”**。学习界面暂时锁定，等待电脑。
3. Windows 学习程序核对“手机 App 标识”；首次同步勾选 **“首次配对：允许用已有进度初始化尚未学习的一端”**。
4. Windows 点击 **“数据线同步”**。手机若询问是否接收电脑档案，确认这是要迁入的档案后再同意。
5. 等待手机显示已保存并发送确认，且电脑显示 **“双向同步完成”**。
6. 手机点击 **“退出同步准备”**，再拔线、继续学习。

日常同步沿用同一学习档案，通常不用重新勾选首次配对。只有手机或电脑其中一端完成了保存，仍不算双向同步完成；出现超时、断线或未确认时，保留两端 App 和记录，重新连接后再同步。

如果出现离线笔记或设置冲突，按界面选择保留的内容或合并文字，再保存处理结果。

## 5. 安装后逐项验收

这些步骤目前仍待真机执行，看到实际结果后才能勾选。

- [ ] 手机首次打开能看到词库，没有原生存储错误；Windows 迁入的进度与旧网页一致。
- [ ] 第一次 USB 同步得到手机保存确认和电脑“双向同步完成”，两端进度一致。
- [ ] 开启手机飞行模式，学习几个词、写一条笔记；退出 App 再打开，记录和断点仍保留。
- [ ] 手机离线学习 20 个词，电脑学习另 10 个词，再用数据线同步；两边的单词记录和笔记均保留。
- [ ] 检查“认识”、熟知标记、恢复复习和撤销在两端同步后的结果。同词同一天的重复反馈不会重复推进复习日程。
- [ ] 正常同步完成后再次同步，已学数量不重复增加。
- [ ] 中途断线后能够重试；未收到手机确认时，电脑不提前显示双向完成。
- [ ] 完整同步档案成功保存到外部文件夹；它保留配对身份和操作记录。

验收初期请保留旧 HTML 和原始 JSON 备份。若需要分享错误信息，先遮住 Apple 账号、密码、验证码及其他个人信息。

## 6. 续签与更新时保留进度

Sideloadly 官方 FAQ 说明，免费 Apple 账号签名的 App 有效期为 **7 天**；可在到期前续签。自动刷新需要满足工具运行和设备连接等条件，首次使用先确认手动续签可行。[Sideloadly 官方 FAQ](https://sideloadly.io/)

1. 手机还能打开时，先导出一份完整同步档案，并与电脑完成同步。
2. 继续使用原 Apple 账号、相同的最终 Bundle ID，以及原来的签名安装设置。
3. 用 Sideloadly 对相同 App 重新签名、覆盖安装，**不要先删除手机里的“九分词汇”**。删除 App 可能连本地数据库一起删除。
4. 打开手机 App，核对学习进度、熟知标记、笔记和断点，再进行一次 USB 同步。

若 App 已到期打不开，也先保留原 App，尝试用相同身份覆盖续签，不要先卸载解决。覆盖安装后的数据保留仍需本机实际验收；完整同步档案是恢复记录的依据。更换账号或 Bundle ID 可能形成另一个独立 App，应先备份、核对迁移后再处理。

安装包、程序目录和学习档案用途不同：IPA 用于安装或更新，**完整同步档案**用于保存和恢复你的学习记录。GitHub 编译产物里没有个人学习进度。
