## 开发目标

让用户自己导入的一份“单词＋中文”词表，也能逐步补齐可靠资料、获得好用的巧记、听到单词和例句，并进入每日复习。学习主线保持为：**开始任务 → 回忆 → 按需看释义和巧记／听读音 → 反馈 → 自动保存**。

继续维护 Windows 本地学习，沿用四个入口：今日学习、词库与笔记、学习记录、备份与设置。增加的管理工具放进现有页面，不再扩展独立导航。

巧记是核心：能从熟悉线索帮助还原拼写，并联系到指定词义，比“每个词都有一段故事”更重要。保留已有个人联想及学习记录；资料更新不重置熟知、复习日期或当天额度。

## 制定计划时的 2.0.0 基础

- 1,493 条内置词汇、巧记、例句和离线英美正常／慢速单词音频。
- 每日新词数量、学习日、预计首轮完成时间、间隔复习、熟知及撤销。
- 自建词书、Excel／文本／粘贴导入、列映射、重复项预览、词书间共用学习进度。
- 离线词典补齐释义和音标、逐字段选择、来源保留。
- 个人熟词线索、联想画面和笔记；完整学习 JSON 备份及内部快照。
- 本地状态快照、异步保存、失败回退、关窗和刷新等待保存。

制定时的主要缺口：自加词缺少统一资料编辑；多套结构化巧记不能通过用户资料导入；没有 AI 待补任务和结果导回；例句按钮播放单词；自加词没有音频生成；词书筛选未与每日学习范围完整衔接。实现状态以上表为准，以下保留各项设计与验收目标。

## 功能 1：资料缺项筛选与单词编辑

### 用户操作

在“词库与笔记”按“缺释义／缺音标／缺巧记／缺例句／缺音频”筛选，也可查看“待完善”。打开词条后，直接编辑中文、词性、音标、英文例句、译文、搭配、来源及巧记。

“缺资料”和“能否开始学习”分开判断：有适用释义即可自行加入计划，缺音频或巧记不强制阻止学习。通用占位提示不计为已经有巧记。

巧记支持两种输入：简单的“熟悉线索＋联想画面”，以及可选的结构化方案“片段／借用步骤＋场景＋还原拼写”。多条方案仍按序号集中展示。用户可以修改、停用或删除方案，不恢复已删除的反馈按钮或手动回忆质量选择。

### 实现方式

- 以稳定词条 ID 保存用户资料，沿用现有词书与内容覆盖机制；为结构化巧记、搭配和来源新增带版本的资料扩展，避免塞进学习反馈历史。
- 个人已编辑的内容优先；随软件更新的内置资料不能覆盖它。提供明确的“恢复内置资料”，先预览差异。
- 释义、音标、例句等普通字段继续走简单表格导入；多套巧记使用专用结构，不让 Excel 单元格承担整份嵌套 JSON。
- 本阶段编辑原词条资料，暂不支持把一个已学习词改成另一个英文拼写；拼写错误通过后续专门的词条更名／合并设计处理。
- 已有关联音频的正文被修改后，标记该音频过期，不能继续将旧声音当作新正文播放。

### 完成标准

只导入“英文＋中文”的 20 个词后，可以在软件内补改资料并展示多条巧记；退出重开、备份恢复后保留；词条 ID、历史、熟知、笔记和到期日期一致，缺项筛选反映实际内容。

## 功能 2：AI 补全任务与导回

### 用户操作

选词 → 点“交给 AI 补全” → 选择缺失字段 → 复制任务或导出文件 → 发给自己使用的 AI → 将结果粘贴／导入软件 → 检查预览 → 采用选中的字段。

先完成外部 AI 交接。软件内直接接入模型、保存 API 密钥或运行本地大模型留待独立评估，不作为本功能的前提。

### 任务和结果

- 在项目根目录提供 `AI补全指南.md`、版本化 JSON 示例和项目专用提示词。软件导出的任务自带这些必要说明，无法读本机项目的 AI 也能使用。
- 每条任务包含固定 ID、英文、指定中文义项／词性、待补字段、必要的已有资料、词条内容版本和任务编号。默认每批 20—50 词，可拆分、继续导回。
- 导出前显示内容预览；默认只带词汇资料，不带学习历史、笔记、个人联想、档案身份或本机路径。只有明确选择需要作为上下文的资料才导出。
- 结果必须对应原任务和原词条。区分“已给候选／需要核查／无法补全”，无法提供的项目可留空并说明原因。
- 允许补巧记、例句、译文、搭配及有依据的词性／音标；默认不改用户指定的英文和中文义项。
- 导回逐项核对 ID、英文、任务版本、长度及结构；生成期间用户又编辑过的字段要提示差异，不能用旧结果覆盖新修改。
- 支持逐词、逐字段采用和跳过，保存来源与采用批次。同一结果重复导入不产生重复方案；格式错误不部分保存，取消不改词库。

### 巧记质量要求

1. 优先用熟词直接组合，其次用清楚的增、删、换字母或基础词变形；能合理使用词根词缀时单独标明。
2. 每个片段和变换必须还原目标拼写。短语保留真实空格和连接符，界面不给空格单独制作提示卡。
3. 场景必须联系用户指定的词义，让用户能理解为什么从线索想到这个意思。只复述词义、空泛故事、难词互相解释都不能当作优质补全。
4. 对提示词给出简单中文释义；用户不熟悉提示词时可另写方案。无法判断一个词对用户是否熟悉，不宣称机器已验证其记忆效果。
5. 人为拼写、拼音、形状或近音联想注明为助记；不当作真实词源或标准英语读音。
6. 事实资料给出实际可核查的来源；原创助记注明为原创。没有查到时保留待核查，不编造引用。

字母还原由程序检查；语言是否准确、场景是否好记仍需人工审核。先用熟词组合、派生词、短语、多义词和难拆词组成的 50 词样本验证，再推广，不直接重写全部内置巧记。

### 完成标准

任意一批自加词能完成“导出任务 → 外部 AI 返回 → 预览 → 选择 → 保存 → 学习卡展示”。编号错误、错误拆分、过期字段和重复结果有清楚处理；采用内容能备份恢复，原进度不变。

## 功能 3：内置例句整句朗读

### 用户操作

保留单词的“播放读音”按钮，将例句区域右上角改为“听整句”。它播放当前显示的完整英文例句，学习卡和词条详情的行为一致；没有例句时明确显示暂无例句。

### 实现方式

- 延续已选择的英式 Emma、美式 Heart 音色。先完成内置例句的预生成和离线播放，运行时不等待合成。
- 正常／慢速继续可选；先试听播放器减速效果，效果不满足要求时再独立生成慢速资源，控制新增文件量与包体积。
- 通过正文、口音、音色、语速和生成版本关联音频。改例句后旧音频失效；切词、换句或重复点击时停止上一段，避免多段叠播。
- 生成、音频校验与打包独立于反馈保存；不在评分按钮链路中加载模型。
- 抽样检查短句、长句、标点、数字和多音词。文件哈希及辅助转写不能代替试听和发音核对。

### 完成标准

断网点击“听整句”能从头读到尾；切换英美、速度、词条、任务、详情页后无错配或叠播；正文变更不播放过期声音，原单词音频继续可用。

## 功能 4：自加词与例句离线音频

### 用户操作

选择缺音频的词 → 生成读音 → 查看进度／试听 → 采用。新增或修改词条后只处理有变化的文本；失败项目可重试，已完成项目复用。

### 实现方式

- 核心安装包继续只负责播放；本地生成器及模型作为可选资源。首次需准备生成组件，准备后可在本机离线生成，避免把大模型和开发环境强塞进主程序。
- 使用时由软件检查组件并启动独立后台任务，不要求用户日常手敲 Python 命令。具体打包体积和兼容性在本阶段先做小样验证。
- 先支持单词，再支持自加例句；保留口音与速度选择、进度、取消、失败重试和试听。合成不占用学习界面的主执行路径。
- 保留词性／义项和读音修正入口；多音词、专名和无法确定读音的词须核对，不保证文字转音频天然正确。
- 音频单独存放在用户数据目录，不把二进制塞进学习 JSON。按内容索引，重复文本复用；清理失效文件前检查引用，不能误删仍被使用的声音。
- 本阶段同时提供包含自加音频的完整迁移包：学习 JSON＋音频＋清单与校验。旧 JSON 仍可恢复文字与进度，但不能宣称它包含音频文件。

### 完成标准

一份包含自加词和例句的词表可生成、取消、重试、试听；关闭重开和断网后可播放。将完整迁移包导入隔离的另一份安装后，记录与音频齐全，缺少生成组件也可学习和播放已有声音。

## 功能 5：词书学习范围与轻量管理

### 用户操作

“调整计划”增加要学习的词书范围；每日总新词量继续只设一份。也可从当前词书启动自主回顾。词书支持改名、调整章节顺序、归档及移出词书。

### 规则

- 多本词书中的同一个词共用进度，每日额度只计一次；相同拼写但明确建立的独立义项保持独立。
- 新词按所选范围安排。到期复习保留已加入计划的词，单纯切换词书不能让旧词悄悄消失；需要停止安排时另用“暂停”，并预览影响。
- 预计完成时间按当前启用范围中的未学词去重计算，区分首轮新学与后续复习。
- 归档只是整理词书入口；移出一本词书不删除词条、个人资料、历史或其他词书关联，也不默认为暂停。移出后无所属词书的词保留在“未分组”。
- 暂不新增每本词书独立日历、互相竞争的每日额度或多个学习档案，保持安排规则可解释。

### 完成标准

两本含重复词的词书共用正确进度与新词名额；改范围、归档、移出、恢复不丢记录，不意外重新学熟知词；完成日期随实际范围合理更新。

## 功能 6：词书资料包与可控批量撤销

- 导出一个或多个词书的词汇、顺序、释义、例句、巧记、来源和可选音频，默认不含个人学习进度或笔记。导出前展示内容和大小。
- 导入资料包仍走匹配、差异预览与确认；更新资料不覆盖收件人的学习历史。完整档案恢复与词书资料导入使用不同入口和明确名称。
- 为批量导入、资料补全、AI 采用记录必要的变更前值；提供“撤销本批资料修改”的预览。
- 撤销仅处理该批资料与词书关联，不回退后来新增的学习反馈。后续又修改过的字段列为冲突，跳过或要求明确决定。
- 已经学习的新词不随撤销被删除；先支持可安全识别的撤销，不实现任意历史倒带。

完成标准：资料包往返保留内容与来源；默认不泄露进度或笔记；跨批编辑后撤销不会删除后来学习的记录，失败和取消不改数据。

## 每个功能都必须满足的要求

- **响应**：日常评分不调用 AI、词典扫描、语音生成或全库资源加载。分开测量下一词显示与保存完成，沿用当前性能夹具并扩展样本，出现明显退步先定位原因。
- **容量**：新增资料会增大学习快照，先用 1,493 词及 10,000 词／较长历史的隔离样本检查保存、搜索、启动和备份。确有瓶颈时再针对持久层优化，不预先重写整套数据库。
- **可靠**：无效输入不覆盖原档，保存失败不能提示成功，刷新／退出等待落盘，升级前保留可恢复副本。新资料字段同时更新验证、备份、迁移和渲染，旧格式可读边界要说明。
- **学习记录**：资料更新前后比较词条 ID、卡片、历史、熟知与复习日期。合法的计划调整需单独说明，不能由内容导入隐式触发。
- **维护**：沿用 `web/` 和 `shared/`，将新增资料、AI 任务和音频逻辑放到明确模块，避免继续扩大单个界面文件；只在改动涉及处拆分，不先做大规模框架迁移。
- **发布**：开发与测试使用隔离数据；更新简明说明与实际验收结果。源码、程序、内容包、生成器和模型的版本及用途分清，主程序不因维护工具而失去独立运行能力。

## 暂缓范围

本计划不安排手机／USB／云同步、账号体系、内置 AI 聊天、自动后台联网补词、自动改写全词库巧记、成就排行榜、大型统计面板或框架迁移。

独立历史合并、已学习词条更名／合并和新的记忆算法另行设计。先让已有复习规则与上述资料流程稳定，不以增加设置项作为功能完善的目标。

## 下一步交付

先开发功能 1，随后开发功能 2。第一轮目标用一句话说明：**导入自己的词 → 手动或交给 AI 补资料 → 核对采用 → 用与内置词一致的方式学习 → 退出后保留进度。**

用户已要求按计划进行开发。本轮继续完成实现、测试和本机交付；版本公开发布与 GitHub 更新以实际执行结果为准，不因本计划中的目标描述而视作已经发布。
