# 后续开发计划

## 已确认：AI 资料补全任务与导回

用户于 2026-11-04 确认记录此项，待后续单独开发。本轮已实现原方案功能 4：离线词典补齐释义和音标。

AI 补全的预期流程：选择词书或词条 → 导出待补任务／复制任务 → 发给用户选用的外部 AI → 导入结果 → 校验和预览 → 逐条采用。继续保留本地学习与 USB 同步，不要求云端学习账户。

- 在软件中设置“交给 AI 补全”入口，自动列出缺少的资料，附带固定词条编号、英文、指定中文释义、已有资料与缺失字段。
- 内置项目专用提示词和完整示例，明确熟词搭桥、字母变化、词义联系、可靠词根词缀与人为联想的区别；不合适的方案标记待完善，不生成空泛套话。
- 在项目根目录提供 AI 补全指南，说明任务格式、来源要求、允许更新的资料和校验方法；无法访问本机文件的 AI 可直接读取自包含的导出任务。
- 定义版本化的任务和结果格式。保留词条 ID，仅补学习资料；不导出密码、签名资料或个人学习历史。
- 导回前核对编号与英文、必需字段、字母拆分能否还原拼写。保留原值、差异和来源，由用户采用、修改或跳过。
- 多条巧记、拆分步骤和来源需新增专用格式及渲染支持；当前普通表格导入不承担结构化巧记导入。
- 默认使用用户自行选择的外部 AI。项目内直接调用模型服务／本地文本模型另行评估，不自动接入或索取 API 密钥。
- 读音由独立语音组件生成，AI 文本补全不等于离线音频已经准备好。
