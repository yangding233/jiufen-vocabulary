# 实机验收

## 已有自动化

1. 共用核心：独立词合并、同日同词去重、跨日乱序、熟知/恢复、撤销、不丢笔记、设置冲突、自建词冲突、损坏数据、原生JSON字段乱序。
2. Windows SQLite：事务保存、验证失败不覆盖、持久设备ID、备份、pending批次。
3. 同步管理：必须等正确回执、超时重试、新批次拒绝旧回执、取消、首配拒绝覆盖两份独立进度。
4. 文件传输：仅固定Exchange路径、临时文件/完整文件、无效JSON不替换。
5. 界面：native保存、模拟磁盘失败回退、熟知撤销、笔记、旧JSON首次迁移、完整同步档案恢复、同步冻结、冲突解决、手机宽度。
6. 真实Electron及打包后的Windows可执行程序：保存、关进程重开、断点、熟知撤销、笔记、renderer隔离。
7. 模拟iOS桥：首次配对、接收后保存再回执、二次合并、拒绝坏包。
8. Windows 0.1.2：冻结程序 SSL 自检、签名 App 自动识别、真实 Electron 窗口检测手机并填写实际 App 标识。
9. 2026-11-03 / 0.1.3 巧记更新：30 项 Node 内容、同步与存储测试和 11 项 Python USB 测试通过；原网页、模拟 iOS 桥与新增巧记兼容性界面测试通过。全词表精确拼接、基础词链无环、非 memory 词法字段与更新前逐项一致；旧内置占位不会覆盖新方案，个人联想、停用、反馈和计划保留。打包后的 Windows 0.1.3 用隔离数据库通过保存、退出重开、撤销、笔记和 USB 检测路径；本轮没有据此新增真机完整合并验收结论。
