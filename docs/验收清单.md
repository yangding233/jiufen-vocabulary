# Windows 2.0.0 验证清单

本文件按 2026-11-04 的实际结果记录。所有本轮测试使用隔离档案及合成数据，未读取或改写用户日常学习数据库。历史手机／USB测试结果不作为当前桌面版通过依据。

## 数据与迁移

- [x] 旧 schema1／schema2 同步档案可以转换为本地当前状态，保留卡片、历史、计划、笔记、熟知与词书。
- [x] 转换前独立保存完整旧档案；无效输入不覆盖当前数据。
- [x] 内部旧快照和旧完整 JSON／同步档案可预览与恢复。
- [x] 恢复先保留当前档案副本，取消或校验失败不替换记录。
- [x] 新格式退出重开后内容与学习断点一致。

## 核心操作与性能

- [x] 快速连续评分、撤销、熟知与恢复行为正确，没有重复或丢失。
- [x] 保存失败会显示失败并允许重试，不误显示已经保存。
- [x] 未完成保存时关闭程序会安全处理，重开无丢失。
- [x] 实际 Electron 中按钮到下一词显示延迟有记录，测试说明词条数、历史／旧操作量、运行环境和指标。
- [x] 日常评分不再调用跨设备操作记录／合并或重放完整旧日志。

## 保留的工具

- [x] 词表导入、列映射、重复词处理、草稿词和批量确认通过。
- [x] 离线词典按需加载、保护已有内容、逐字段采用与来源保存通过。
- [x] 个人联想／笔记、正常／慢速读音、大字号和旧反馈保留。
- [x] 1,493 词、5972 个音频与50,000条参考词典的资源校验通过。

## 收敛与发行

- [x] 当前界面无 iPhone、USB配对、同步冲突、等待回执等入口。
- [x] 桌面运行及打包不需要 Apple 服务、USB Python组件或 macOS。
- [x] iOS源代码、远程构建、USB传输器和对应测试已删除。
- [x] 最终 Windows 2.0.0 打包程序通过实际学习／音频／笔记／断点、导入、词典补全和生命周期四组回归。
- [x] 发布归档未包含个人记录、签名资料、测试数据库、模型或开发缓存。

## 本轮已执行检查

- 核心与数据检查：57 项通过，覆盖桌面快照、旧档案只读转换、词书、导入、巧记、复习工具、内容包及离线词典。
- Windows SQLite：10 项通过，覆盖原档案独立备份、迁移、事务保存、旧快照读取及恢复。
- 内容构建一致性检查通过；资源检查通过 1,493 词、5,972 个音频和 50,000 条词典资料。
- 6 组隔离 UI 检查通过：基础学习、巧记、保留的学习工具、词表导入、离线补全、延迟保存时的界面响应。
- 真实 Electron 开发版的学习／退出重开、导入、词典补全与生命周期检查通过。
- 人为将异步保存延迟 800ms 时，下一词在 26.8ms 显示；保存期间重复评分受保护。关闭和 F5 刷新等待保存完成，冷启动后反馈与断点保留。
- 最终打包版刻意将异步保存延迟 800ms，下一词在 20.5ms 显示；关闭和 F5 等待保存后继续，记录与断点完整。
- 原备份合并入口已删除，统一为预览后恢复；旧档案文件输入上限为 55MB，具体格式仍通过对应校验器；撤销和巧记停用在保存成功后再提示／刷新。

程序目录在复制最终文档前的对比中，从约 479MiB／1.24 万文件缩小为约 405MiB／0.61 万文件，减少约 74MiB（约 15%）。文档变动会使最终归档大小略有变化。

## 本轮性能记录

在当前 Windows 开发机、Electron 41.10.6 开发版中，每种场景连续测量 12 次评分。界面指标从触发评分计时到下一次动画帧，并确认下一词已更新；保存指标计时到本机写入成功返回。每次测量前等待前一次保存完成。

| 隔离合成场景 | 下一词显示 P50 | 下一词显示 P95 | 保存完成 P50 | 保存完成 P95 |
| --- | ---: | ---: | ---: | ---: |
| 新档案，1,493 词 | 36.9ms | 55.0ms | 80.1ms | 127.2ms |
| 旧档案迁移后，原 5,000 条操作、2,000 条历史，1,493 词 | 65.8ms | 81.0ms | 171.9ms | 220.7ms |

原始报告位于开发区 `test-results/electron-performance.json`，生命周期报告为 `test-results/electron-lifecycle-timing.json`，均不打包发行。详情与解释见[收敛与性能优化](收敛与性能优化.md)。

以上是小样本实测，P95 在 12 次样本下接近本轮最大值；不是所有电脑的延迟保证。没有在同一夹具上取得旧版的对应指标，不报告加速倍数。原 5,000 条操作仅在迁移时读取，新版日常保存不再保留或重放操作日志。
