# 资料编辑与 AI 补全

在“词库与笔记”可以按缺释义、缺音标、缺巧记、缺例句或缺音频筛选。缺少巧记和声音不妨碍已有释义的词加入学习计划。

打开单词，点“编辑单词资料与巧记”，可以修改中文意思、词性、音标、例句、译文、搭配和来源。巧记可写熟悉线索和联想画面，也可以添加拆分片段，多套方案按序号一起显示。片段按顺序必须还原真实英文；短语空格也要保留。词条英文身份在这个入口中保持不变。

点“保存资料与巧记”前先核对表单内容和提示。资料保存不会重置已学状态、熟知、复习日期、个人笔记或反馈历史；保存失败时原资料保留。

## 交给外部 AI

1. 选择需要完善的词，点“交给 AI 补全”。每批默认最多 50 词。
2. 选择需要补的字段，点“生成待补任务”。复制完整提示词或导出任务文件，发给自己使用的 AI。
3. AI 需要返回指定格式的 JSON。将结果粘贴或导入软件，点“检查结果并预览”。
4. 核对词条、原资料、候选资料与提示，按字段选择后点“采用选中的资料”。已有字段默认保留，替换时需明确选择。
5. 保存后再打开单词，检查巧记、例句和搭配。导入的资料随完整学习备份保留。

默认任务仅包含词汇资料，不包含学习反馈、笔记、个人联想或本机目录。软件不直接调用 AI，不需要在项目中保存 API 密钥。具体结果格式和专用提示要求见项目根目录的 [AI补全指南](../AI补全指南.md)。

无法确定的内容可以标为待核查或无法补全，不强求填满。字母拆分通过检查也不等于这条巧记一定好记。需要调整时可回到资料编辑修改。

如果任务生成后又修改过资料，旧 AI 结果会被标为过期。重新生成任务后再补全；不要手改词条编号或版本绕过检查。同一结果重复导入不会重复添加方案。

AI 补全的是文字资料。词典音标或 AI 音标都不代表音频已经生成；声音由独立的音频功能提供。
