## 已通过的检查

- 核心与数据测试：本轮汇总时 **83 项**通过，含资料、任务、词书、旧档案与容量覆盖；最终新增测试数量以发布前重跑为准。
- Windows SQLite：**10 项**通过。
- 音频资料及服务：**8 项**通过。
- **9 组隔离 UI** 分别执行通过：基础学习、巧记、学习工具、词表导入、离线词典、响应、资料／AI、词书工具及音频界面。
- 词书工具专项检查：预览过程中资料变化会要求重新核对；模拟磁盘保存失败不写入部分结果，重试后成功；主“应用计划”按钮同时应用词书范围。
- 批次撤销拒绝危险路径和无效字段类型；首次编辑旧式投影词书不会误记为需要删除全部原词书成员。
- 隔离容量样本包含 **10,000 词、20,000 条历史、1,000 套巧记**，档案约 **9.22MB**，通过校验及持久化相关检查。

## 响应观测

当前 Windows 开发机、Electron 开发版，每场景连续评分 12 次。测量期间完整例句音频正在后台生成；每次开始前等待上一项保存结束。数据为合成档案，不是用户真实学习记录。

| 场景 | 下一词显示 P50 | 下一词显示 P95 |
| --- | ---: | ---: |
| 新档案，1,493 词 | 33.3ms | 58.3ms |
| 原 5,000 条操作、2,000 条历史的档案迁移后 | 53.1ms | 58.2ms |

较重场景保存完成 P95 约 **553ms**，应与上表的界面反馈时间分开理解。后台合成和当前负载影响结果，12 次样本的 P95 接近最大值；不将本轮数字与旧版直接比较，也不承诺所有电脑相同。原始报告在开发区 `test-results/electron-performance.json`，不包含在发行包中。

## 当前边界

- AI 返回的语义、词源、音标和巧记效果仍需人工核对；格式通过不等于内容正确。
- 生成声音需要可选本地组件及模型；约 1.37GiB 的独立组件已通过真实自加词、完整句子、缓存复用和取消检查。
- JSON 学习备份不包含音频文件；带音频迁移使用完整迁移包。词书资料包默认不分享学习历史或私人笔记。
- 历史版本没有记录变更前值的批次不能凭空撤销；后续被编辑过的字段会跳过，保留学习反馈。
- 本地 Windows 2.1.0 已通过六组真实 Electron 检查：学习、导入、词典补全、关窗／刷新、整句音频及资料／AI。2.1.0 的下载文件与校验信息见 GitHub Releases。

完整资源：1493词、5972个单词音频、2986个句子音频、50000条参考词典。新句子音频约46.42MiB。全部整句音频通过正文、口音、数量、格式与SHA256；语音生成组件可独立运行，约1.37GiB，常规学习与播放不需要它。AI内容及合成读音仍需结合词义核对，不宣称逐词人工审听。
