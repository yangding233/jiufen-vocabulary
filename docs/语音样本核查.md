# 语音样本辅助核查

2026-11-04，对20个词条的英式／美式、正常／慢速音频共80片做了离线ASR筛查。这里只检查这组样本，不代表全部1493词经过真人逐条审听。

## 方法与前后结果

使用本地缓存的 faster-whisper small，CPU int8，beam size 1、best of 1、固定英语、关闭VAD；不提供目标词提示。FFmpeg把音频解码为16kHz单声道float32数组，再送入识别器，避免PyAV接口版本差异。标点和大小写不参与比较；复数词尾及同词重复读法仍参与比较。

| 同一组80片 | 词形匹配 | 重复读法被合并、待复查 | 其它差异、待复查 |
| --- | ---: | ---: | ---: |
| 音素重音位置转换修复前 | 47 | 0 | 33 |
| 修复后完整复测 | 74 | 1 | 5 |

早期筛查暴露了标准IPA转模型音素时的重音位置问题。修复转换并重新生成受影响音频后，以下词的英美正常／慢速四片均识别出预期词形：**contrast、desert、increase、Live nearby、permit、survey**。其中contrast、increase和permit还识别出两次播放；词形匹配本身不能证明两次的重音区别正确。

**audience、audiences** 的四种组合在修复前后都匹配预期词形，复数audiences没有被识别为单数。

## 保留的待复查项

- **presents**：四片均被转写为近音的“presence”。词表义项为礼物，生成目标保留名词的第一音节重音和/nts/词尾；不为提高ASR匹配而改成展示动词的后重音。仍需人工核对/t/及复数尾，不能把近音转写直接当成合格或错误证明。
- **tears**：英式正常／慢速、美式慢速匹配；美式正常被识别为“Cheers”。词表义项为眼泪，需复查这一片的起始辅音和词尾。
- **digest**：英式正常只识别出一次digest，标为重复读法被合并；英式慢速及美式两片识别出两次。识别器可能合并同词重复，仍需核对实际音频是否完整保留动词、名词两种读法。

上述6片没有被自动改写为“通过”。ASR不能证明音素、重音、口音或自然度正确；同形多音词即使两次都转写为同一个英文，也不能证明名词和动词读法已经分开。

## 复现与记录

开发环境已安装faster-whisper，并已有本地small模型时运行：

```powershell
.\.venv-audio\Scripts\python.exe tools/check_neural_samples.py --slow --threads 2 --output build/neural-audio/asr-after-stress-fix.json
```

模型不存在时工具明确报错，不自动联网下载。可用`--model`指定模型目录，用`--ffmpeg`指定本地FFmpeg。报告保存在忽略提交的build目录：修复前为`asr-before-stress-fix.json`，修复后为`asr-after-stress-fix.json`。筛查仅读取开发样本，不访问学习数据库。
