# 词书整理与资料包

这些工具位于“词库与笔记 → 词书整理、资料包与撤销”。先在词书筛选中选择一本书，再操作。当前开发版保留四个主要入口。

## 安排学习范围

在“今日学习 → 调整计划”中，选择“每日新词来自哪些词书”，点“应用词书范围”。

- “全部词库”包括未分组词。
- 选多本词书时同一个词只占一次新词名额，已经有的学习进度继续共用。
- 每日新词仍只设置一份总量；今天已经消耗的名额不会因换范围重置。
- 切换范围只控制新学来源，原先的到期复习仍保留；需要暂停一个词时，使用词条中的暂停安排复习。

## 整理词书

- **归档当前词书**：收起不用的词书，之后可在“已归档词书”中恢复。归档保留词条、学习记录和复习安排。
- **将已选词移出当前词书**：只移除本书关联，保留这个词及其他词书关联；不删除笔记或历史。
- **章节上移／下移**：调整当前书章节的展示顺序，章节内部仍按已有词序排列。
- **查看未分组词**：没有所属词书的词仍在这里，可以打开查看，学习记录不丢失。

## 导出和导入词书资料包

选择词书后点“导出当前词书资料包”。文件为 JSON，包含词汇、章节、顺序、释义、音标、例句、巧记、搭配和来源；默认没有学习历史、熟知状态或私人笔记。音频文件的完整迁移使用“备份与设置”的完整迁移包。

导入时选择文件，先检查预览：

- 已有词默认关联并只补空缺；已有非空资料会保留。
- 需要更新时明确选择“关联，采用包内资料”。
- 同名词存在多个独立义项时，先选定要关联的词条，或选择新建独立词条。
- 不需要的词选择跳过。

确认后资料作为一批保存。预览过期会要求重新核对；保存失败保持原记录，可以重试。重复导入同一份资料包会复用词条及已建立的目标词书。

资料包用于分享或整理词汇资料；自己的进度迁移应使用完整学习备份，不能把两者混用。

## 撤销一批资料修改

展开“撤销最近的资料批次”，点对应批次预览。

程序检查每个字段是否仍等于那次操作保存的值。没有后续修改的项目可以还原；后来已经手动编辑的项目会标成冲突并跳过。确认后只还原可安全处理的资料和词书关联，不撤销之后产生的学习反馈。

已经学习的新词会保留，不会随资料批次一起删除。较早版本没有记录变更前值的批次不能凭空撤销；需要恢复历史档案时，先备份当前进度，再预览完整备份。
